# DECISIONS (append-only)

- **D-001 Rojo, fully file-managed.** The repo is the source of truth; nothing exists only in Studio.
- **D-002 Strict Luau + pure modules.** Game logic lives in `src/shared` modules without Roblox service calls, so Lune can unit-test it. Server/client scripts are thin wiring.
- **D-003 Testing.** Lune unit tests locally (`scripts/check.sh`). Engine-level tests later via the Open Cloud Luau Execution API (T-010). Visual/feel testing is done by the user in Studio via `rojo serve`.
- **D-004 Procedural courses.** Courses are assembled per round from code-defined chunk specs (seeded). No hand-built maps or meshes, which fits headless development and gives replayability.
- **D-005 Round state replication via ReplicatedStorage attributes** (`Phase`, `TimeLeft`, `Round`). No RemoteEvents until a feature needs client→server input.
- **D-006 Access.** GitHub through the PromptQL integration proxy (no tokens in the VM). Roblox API keys only through a PromptQL custom integration; never committed or pasted in chat.
- **D-007 Style.** Tabs, StyLua (column 120), Selene `roblox` std.
- **D-008 Budget discipline.** One S task per session, commit per working step, short script output.
- **D-009 Game:** round-based obby race named Robby (see GDD.md). Chosen by the AI with user delegation. **SUPERSEDED by D-013.**
- **D-010 Gated phases** (user request, 2026-10-29): Research → Planning → user approval → Building. T-001 scaffold is kept as Phase 0 because it is genre-agnostic.
- **D-011 OLU budget** (user rule, 2026-10-29): 50 OLU hard cap per session. Wrap up at 43, close-out started by 45, so 5–7 OLU stay in reserve for state updates, commit and push. Measured with `scripts/olu.sh` (bot OLU total minus the baseline recorded at boot).
- **D-012 Research tooling:** web research goes through PromptQL's built-in Exa search, with short capped answers. Findings and sources are recorded in RESEARCH.md so they are never re-searched.
- **D-013 Direction change** (owner, 2026-10-29): the obby concept is dropped. Robby is a high-quality Roblox action RPG based on the web novel *Reverend Insanity*, with *Rell Seas* as the quality benchmark. The obby GDD is archived in `.ai/archive/`, and "Robby" is now only the repo codename.
- **D-014 IP default:** the world is original and *inspired by* Reverend Insanity. It uses no names, characters, places, plot or text from the novel, unless the owner gets a license. R-012 will confirm or revise this.
- **D-015 Session model:** one fresh bot per session, booted exactly as in AGENTS.md §3. Research sessions use a research-strong model; building sessions use a strong coding model.
- **D-016 Owner input:** goes in `research/inbox/` (never edited) and is listed in VISION.md by R-010. Priority: owner intent > research > AI suggestion.
- **D-017 Helper scripts:**
  - `search.sh`: capped web search.
  - `save.sh`: commit, rebase and push in one step, plus the OLU meter.
  - `olu.sh`: a fresh bot counts from 0; `start` is only for reused bots.
- **D-018 Scope:** build a vertical slice first. Rell Seas quality is the bar for the slice's look and feel, not for the amount of content.
- **D-019 Sample code:** the `src/` code (obby RoundState FSM + HUD) only proves the toolchain; T-002 replaces it. The toolchain and testing decisions above stay, except where they mention the obby.
- **D-020 3D pipeline** (owner, 2026-10-29):
  - Blender 4.2 LTS runs headless in the VM. It is installed on demand by `scripts/blender-setup.sh`, not in bootstrap.
  - Generated assets come from Python scripts in `art/blender/` and are built into `build/art/`; outputs are not committed.
  - Owner-provided assets go in `assets/source/` and are indexed in `INDEX.md`.
  - Final routes are decided in R-015 / P-003.
- **D-022 Autonomous sessions** (owner, 2026-10-29):
  - The owner sends one generic message, and the bot resumes from the repo on its own.
  - Every session commits at least one complete piece of work.
  - Tasks are sized to about 30 OLU of work or less and split into sub-tasks when they don't fit (AGENTS.md §0).
- **D-021 Short reports** (owner, 2026-10-29): the end-of-session report is 5 lines or fewer, and progress chatter is avoided, because output tokens cost the most OLU. Details live in the repo.
- **D-023 IP confirmed (R-012, S4):** D-014 stands; a license is unrealistic (title banned in China 2019, rights with China Literature/author, no game ever licensed). Tightened: never use the novel's title anywhere (name, thumbnails, tags, description), its names, plot, coined terms, text or art. Use our own word for the creatures instead of "Gu". Systems, themes and folklore/xianxia conventions are free to use.
- **D-024 Maturity label Mild (R-017, S4):** target the Roblox "Mild" label for the widest audience; Moderate only if a key feature needs it; never Restricted. RI's dark tone becomes strategy, scarcity and rivalry: no gore, corpses, torture or cruelty; stylised hit effects instead of blood.

- **D-070 Binding core (S13, T-017a):** pure `Binding.step(duel, cfg, dt, channel)`: channelling spends `qiPerSecond` and pushes the bar by `channelRate / (1 + Will×willWeight)`; every `pulseEvery` s the Kith pushes back `pulseStrength × (1 + Will×willWeight)`; not channelling slides back.
