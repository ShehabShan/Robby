# research/

- `inbox/`: owner material (ideas, notes, links, images). **Never edit or delete these files.**
  - Name new files `YYYY-MM-DD-<topic>.md`, saved verbatim.
  - R-010 lists each one in `.ai/VISION.md` under "Owner ideas". A file is processed once it appears there.
- `notes/`: long research notes, named `R-0XX-<topic>.md`. `.ai/RESEARCH.md` keeps the short summary and links here.
- **Copyright:** don't commit novel chapters or long passages. Summaries, paraphrases and short quotes with source links are fine.
