# Original-character identity transport/resolver (S82)

- `CastCharacterIdentity`: bounded canonical length-prefix codec, one model attribute `CastCharacterIdentityV1`; atomic generation/key/user/slot snapshot, frozen decoded values. Cosmetic metadata, never gameplay authorization.
- `Abilities` publishes on original-model join, owner sync, generation renewal and slot revision; clears exact old model on replacement/removal/departure or admission exhaustion. No new remote or listener; existing CastGeneration stays owner-only.
- `CastCharacterClient.snapshot(player)` reads current model's independently published snapshot; `resolve(expected)` returns exact matching current world-descendant original model + live pose, or nil. No cache, subscriptions, yields or receipt-derived relabeling. Missing/streamed-out/late identity is unavailable; retry next admitted frame.
- Replication is eventual: a slot/death update not yet observed cannot be known remotely. One atomic string prevents torn identity tuples, NOT synchronous server liveness. Resolver never supplies damage permission or invents an exact Burst release position.
- Sequence generation renewal can make older poses unavailable even on the same model; accepted world geometry is independent and must survive. Burst original-model continuity needs its own c2c2c contract, not blindly reusing pose eligibility.
