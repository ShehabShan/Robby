# T-043c0b4a — cosmetic resource ownership (S74)
2026-10-31 · D-262–D-263 · pure module, NOT wired to the live renderer.

CastResources is a bounded cleanup registry to consume CastPresentation commands. new(capacity, perCast) fixes owner/resource limits. open(key) returns an immutable unique lease; duplicate keys refuse, so adoption must retain the existing lease. bind(lease, slot, scope, disposer) returns a unique ticket. Every delayed callback tests isCurrent(ticket), not just its cast ID. release(ticket) disposes once; a replacement in the same slot or same cast key cannot be affected by the old ticket/lease.

Ownership detaches before non-yielding disposal callbacks run. Cleanup errors increment cleanupFailures without preventing sibling cleanup. bind transfers disposal responsibility even on refusal (invalid/stale/full/occupied slot): it immediately calls the supplied disposer, so a failed allocation cannot leak. Replacement is explicit release then bind; reentrant occupation refuses the newcomer rather than overwriting it. Callers must not supply a disposer for an already-owned resource again.

retirePose permanently closes pose admission for that lease, removes all pose tickets before callbacks, and leaves world effects alive. clear retires the exact lease and all remaining resources; reentrant reopening creates a different lease. destroy closes admission globally before detaching owners. This is not a scheduler, renderer, or garbage collector: the bridge MUST consume all CastPresentation tick/event clear actions, own every timer/connection/track/particle cleanup, and run tick even without incoming messages. Bind the lease/ticket before enabling a callback that could fire synchronously. Disposers must not yield; error isolation cannot repair an engine disposer that itself fails to release an object, so bridge telemetry must surface cleanupFailures.
