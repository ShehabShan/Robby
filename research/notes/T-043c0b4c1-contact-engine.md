## Integration and ownership
- `CastContactClient.start(catalog)` requires an already-started `CastReceiptClient`; it borrows both inboxes and returns an idempotent stop function. Repeated start returns the existing owner, not another heartbeat. `state()` exposes existing dispatcher counters for diagnostics, not mutation.
- One Heartbeat drives the real `CastContactDispatch` using local elapsed and server clocks. At consumption, `CastCommandMap.contact` resolves optional same-cast metadata from the existing receipt inbox, including retained acceptance after terminal. Generic impact is immediate when metadata is absent; later acceptance cannot replay or upgrade it.
- `CastContactFx.render(frame, command)` binds one unparented Part tree before activating it. ParticleEmitter + BillboardGui + TextLabel are children; parenting failure destroys the unowned child before propagating failure. Dispatcher failure then destroys the bound tree. A stale ticket prevents emission. No tweens, delayed tasks, Debris ownership, frame-specific connections or secondary metadata cache.
- Every tree is four Instances. Existing contact cap128 bounds active trees to128 (512 Instances); emitter burst is clamped0–32 and particle lifetime cannot exceed the remaining local lease. This is a conservative initial ceiling, NOT device-profiled performance evidence.
- Position and amount come only from the confirmed receipt. Damage text reuses Shared.HitFeel. Existing Rimeshard hit FX IDs choose pale frost; missing/other styles use white. No client-inferred hit, crit, Chill, target pose, character, camera impulse or attack-track pause.
- Contact leases expire after Config.CastContactPresentation.effectSeconds (0.6s) of local time, independent of presentation terminals or server-clock reversal. Stop destroys the dispatcher/resources but not borrowed inboxes, so restarting the renderer cannot replay consumed contacts.
- Stop the contact owner BEFORE the receipt owner. If reversed accidentally, the next heartbeat fails closed and disconnects the contact owner too. Whole receipt restart retains its existing anti-replay watermark.
