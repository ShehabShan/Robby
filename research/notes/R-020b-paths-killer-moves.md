# R-020b — RI Paths & combo moves in depth (S7, 2026-10-30)

Deepens R-011 §1 and R-019. Sources are fan wikis/summaries, not the novel (depth unverified).
IP rule (D-014): RI terms appear only here, to describe the source. Game content uses Robby mirror names
(Path, Path Marks, Mastery, Weave, Weave Loom, Array, Kith, Qi).

## 1. Findings (sourced) → Robby mirror

| # | RI finding | Src | Robby mirror (original) |
|---|---|---|---|
| 1 | Power is divided into many thematic paths (strength, fire, wisdom, rule…), some with sub-paths. | [1][2][3][4] | **Paths:** 5 at launch (Moon, Wind, Flame, Stone, Tide), each with 1 later sub-Path. Original themes/names only. |
| 2 | Path marks are traces of a path held in the body; more marks multiply that path's moves, and enough marks can lift a move to the power of a higher rank. | [5][6][7] | **Path Marks:** per-Path counter earned by Binding, quests and Weave use. Each Mark adds % power to that Path's moves; Mark thresholds visibly "upgrade" a move's VFX. |
| 3 | Attainment is a separate ladder of understanding (5 main levels with "quasi" steps between); it improves control, creation of new moves, and lets experts swap combo parts. | [8][9][10][11] | **Mastery tiers** (Initiate → Adept → Master → Sage → Paragon), use-based per Path. Unlock Weave slots, cheaper Weave edits, and better Crucible odds. Separate from Rank, so skill ≠ only grind. |
| 4 | A combo move = a fixed, named set of tools used as one technique; one core tool defines the effect and path, supports amplify/stabilise it. Stronger than parts, but costs more essence and mental strain. | [12][13][14] | **Weave = 1 core Kith + 1–3 supports**, built in the **Weave Loom**. Core sets the effect; each support adds one modifier (range, burst, slow, pierce). Higher Qi + Strain cost. |
| 5 | Designing a combo move is hard (timing, storage, aim) and acts like an incomplete recipe; understanding-focused methods speed up creation. | [12][14] | **Weave discovery:** hint scrolls reveal partial Weaves; the Loom shows "resonance" when a valid pair is placed (no blind guessing on mobile). |
| 6 | Marks of different paths conflict (e.g. fire vs water); mixing paths in one move wastes power through friction, so most specialise in 1–2 paths. | [15][16][17] | **Path Friction wheel:** each Path has allied and opposed Paths. Opposed supports in a Weave cut its power (shown as a % in the Loom). Encourages a main + secondary Path build. |
| 7 | Multi-path combo moves are stronger, more versatile and harder to counter, if friction is managed. | [15] | **Hybrid Weaves:** late-game, high Mastery reduces friction; hybrid Weaves get a unique effect. A long-term build goal. |
| 8 | Areas dense with a path's marks suppress opponents with fewer or conflicting marks. | [16] | **Path Ground:** zones/bosses arenas tuned to a Path buff matching players and debuff opposed ones. Makes Reach choice and party mix matter. |
| 9 | A balanced kit covers attack, defence, healing, storage, movement and investigation, arranged around a core. | [18] | **Kith role tags:** Strike, Guard, Mend, Carry, Stride, Seek. The loadout UI warns on gaps (e.g. no Guard). |
| 10 | Group battle formations coordinate fighters and can amplify moves or fuse them into one force. | [19] | **Party Arrays (post-M1):** 2–4 players stand in a shape and channel; the group fires one big Weave. Strong co-op hook. |

## 2. → Implications for Robby (GDD change candidates for P-006)
1. Fix the launch Path list at 5 with a Friction wheel (rows 1, 6).
2. Path Marks = per-Path power scaling with visible VFX upgrades (row 2).
3. Add Mastery tiers per Path, independent of Rank (row 3).
4. Weave = core + supports in a Weave Loom with resonance hints (rows 4, 5).
5. Kith role tags + loadout gap warning (row 9).
6. Path Ground in Reaches/bosses; Party Arrays and Hybrid Weaves parked for post-M1 (rows 7, 8, 10).
