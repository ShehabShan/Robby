# Prepared Wind Step engine driver — S88, 2026-11-01

## Implemented (not live)
- `src/server/WindStepDriver.luau`: `prepare(player, profile, direction)` reserves one original-character lease; `commit(acceptedAt)` acquires server ownership; `stop(keepVelocity?)` is idempotent; `active()` reports committed, open leases. No callers from live init/Abilities/input. No payment, immunity, guard or Config changes.
- Prepare validates original root/humanoid/assembly, supported dimensions/mass, collidable body overlap and ownership capacity; creates disabled world-XZ Plane LinearVelocity, Attachment and five listeners. Commit repeats geometry/identity/resource checks, snapshots auto/manual ownership and fails closed. Uncommitted reservations expire after50ms (including commit-time check).
- Plane force per axis is mass*6000 for mass<=1000; no Y force, WalkSpeed, AutoRotate or position writes. Root dimensions/collision group/mass changes terminate instead of silently changing captured bounds.
- PreSimulation computes prospective budget from max(covered simulation time, server elapsed), sweeps current root-oriented volume with skin and enables force for one simulation; PostSimulation disables it and releases terminal frames. A missing Post, backwards/nonfinite clock or >50ms wall/physics step stops, never catches up. Only COMPLETED simulation contributes residual cleanup.
- Independent guarded teardown disables/destroys force, attachment/listeners, removes positive dash-axis residual capped at last applied target, then restores captured network mode only on surviving original assembly still manually server-owned. Does not write replacement root/new owner's velocity. Y/perpendicular/additive excess/reverse velocity preserved. An external replacement-velocity knockback must call `stop(true)` BEFORE applying its velocity: arbitrary velocity provenance cannot be inferred. No other server/shared velocity writer was found in S88 audit.
