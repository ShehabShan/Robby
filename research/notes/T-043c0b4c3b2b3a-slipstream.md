## Immutable Self metadata contract (design only; D-309)
- Extend CastAccepted with an explicit optional `selfMotion` struct, not overloaded projectile range/speed/centreMode. Version1 fields: distance, duration, brake, fade. Source from server-authorized woven move's motion policy plus server-approved visual fade; never client catalog reconstruction. Require version1, distance/duration/brake validated by WindStep.profile, fade in(0,.12]. Validator copies/freezes values.
- Presence only for Wind Step Self; omission leaves other moves unchanged. Unsupported/missing invalid Self snapshot => no invented movement effect; record diagnostics. Preserve existing immutable identity (castId/requestKey/generation/characterKey/slotRevision/casterUserId) and acceptance timestamps through receipts, copy/equality checks, command metadata and bounded stores. Do not add remote position streams for this effect.
- Self releaseAt=acceptedAt; natural expireAt=acceptedAt+duration+fade (.36s). Server iframes remain their own .18s status deadline. Update CastSchedule using explicit Self motion duration+fade, NOT effect.seconds, at activation; do not stretch iframes to visual lifetime. Do not mark receipt terminal at .18s simply because protection ended.
- Each adapter samples admitted common-clock elapsed and planar speed from the ORIGINAL character. No root lookup by replacement Character. `stoppedAt` is a once-latched observed halt time within[0,duration]; engine decides using its verified original-character sample or authorized motion stop. Planner never decides collision. Never replay missed travel or launch when acceptance arrives late; expired frames hidden. Predicted outline <=.06s, no accepted gust/iframes claim.
- Death/removal loses original-character attachment and cancels owned effects; never adopts new character. Clear local stop latch only when releasing that cast's owned tree. Observation disagreement changes cosmetics only; it must not alter server motion or payment.
- Transport change requires complete copy/validate/equality/roundtrip tests, stale/unknown versions, missing original identity and bounded pool tests. No startup change until b3b+atomic c3b2c. Slot change must not manufacture a new character or restart accepted movement.
